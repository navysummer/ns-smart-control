# ns-smart-control

智能控制小程序 - 古风诗意风格

## 项目简介

这是一个基于 uniapp-x 技术栈开发的智能家居控制小程序，支持华为、海尔、格力、小米等常用智能家居平台的设备控制。界面采用古风+诗意的设计风格，为用户带来独特的使用体验。

## 功能特性

### 核心功能
- **家庭管理**: 创建家庭、添加家庭成员、管理家庭设备
- **设备控制**: 支持灯光、空调、窗帘等多种智能设备的控制
- **场景模式**: 预设诗意场景（晨曦初露、月明风清、温馨归家等）
- **权限管理**: 家长/成员权限控制，家长可添加设备，成员可控制设备

### 智能家居平台集成
- 华为智能家居
- 海尔智能家居
- 格力智能家居
- 小米智能家居

### 界面特色
- 古风配色：采用传统中国色（檀木色、琥珀色、宣纸色等）
- 诗意场景：每个场景都有诗意的名称和描述
- 书法字体：使用楷体等传统书法字体
- 古典元素：融入传统纹样和装饰

## 快速开始

### 环境要求
- Node.js >= 16.0.0
- npm >= 8.0.0

### 安装依赖
```bash
npm install
```

### 开发模式
```bash
# 微信小程序
npm run dev:mp-weixin

# H5
npm run dev:h5
```

### 构建
```bash
# 微信小程序
npm run build:mp-weixin

# H5
npm run build:h5
```

## 设计规范

### 配色方案
- 主色：#8B4513（檀木色）
- 辅助色：#DEB887（琥珀色）
- 背景色：#FFFAF0（宣纸色）
- 卡片色：#FFF8DC（淡黄色）
- 文字色：#2F1810（深褐色）
- 边框色：#D2B48C（沙色）

### 字体
- 主要字体：STKaiti, KaiTi, SimSun, serif
- 标题字号：36rpx-48rpx
- 正文字号：28rpx
- 辅助字号：24rpx

### 间距
- 小间距：8rpx
- 中间距：16rpx-24rpx
- 大间距：32rpx-48rpx

## 注意事项

1. 智能家居平台 API 需要申请相应的开发者账号和密钥
2. 实际使用时需要替换 mock 数据为真实 API 调用
3. 设备控制需要确保设备在同一局域网或通过云服务连接
4. 建议在真机上测试扫码和设备控制功能
